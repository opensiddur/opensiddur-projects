# opensiddur-projects

Jewish Liturgy sources in TEI, suitable for use with the Open Siddur compiler/exporter in [opensiddur-processor](https://github.com/opensiddur/opensiddur-processor). Original sources are in the [sourcetexts](https://github.com/opensiddur/sourcetexts) repository.

The books built from these sources, as electronic books (HTML) and printed books (PDF), are released monthly. [DOWNLOADS.md](DOWNLOADS.md) lists the latest release's books.

Copyright license information for each file is in the TEI header's licence element in each file.
